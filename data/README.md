# Dataset Access

This benchmark repository does not store raw/generated datasets.

Please download all required data files from:
- https://drive.google.com/drive/folders/1jFUpqZkpE0wMmp8MievHeYyjzy94CObM?usp=drive_link

Typical files used by the pipeline:
- `turbine_80.json`
- `wind_plant_data.json`
- `qa_dataset_debug.jsonl` (or your regenerated equivalent)

Place downloaded files in the repository root, or update CLI paths when running scripts.
